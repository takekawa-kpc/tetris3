# Issue 17: UI（ダークモード、ネオン調、アニメーション）

## 概要

ゲームのUIを実装する。

## 仕様

### コンポーネント構成

```
App
├── Header (タイトル + ハイスコア)
├── GameArea
│   ├── Field (10x20 グリッド)
│   ├── CurrentPiece (現在ピース)
│   ├── GhostPiece (落下位置の半透明ガイド)
│   ├── HoldPiece (保持ピース表示)
│   └── NextPiece (次ピース表示)
├── Stats (スコア・レベル・ライン数)
└── Controls (キー操作ガイド)
```

### デザイン

- ダークモードをデフォルト
- ネオン調のテトロミノ色
- グリッドラインは薄く（opacity 0.1）
- スムーズなアニメーション（フェードイン・ライン消去エフェクト）
- PC解像度（min-width: 768px）に最適化
- フィールドは画面中央に固定
