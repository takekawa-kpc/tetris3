# Issue 7: ランディング（ハードロック、30tick = 1.5秒硬直）

## 概要

ピースが接地後、硬直状態に入るランディング機能を実装する。

## 仕様

- ピースが接地後、硬直状態に入る（30tick = 1.5秒）
- 硬直中：回転・移動は可能、ドロップのみ即時固定
- 硬直中はピースが「硬い」色で表示

### 硬直解除条件

- 硬直時間が経過
- ハードドロップ（Space）で即時解除

- [ ] 硬直タイマー（30tick = 1.5秒）
- [ ] 硬直中のアクション制限（ドロップのみ即時固定）
