# Issue 16: ゲームステート管理（idle / playing / paused / gameover）

## 概要

ゲームのステート管理を実装する。

## 仕様

### ゲームステート

| ステート | 説明 |
|---------|------|
| `idle` | 待機中（ゲーム未開始） |
| `playing` | ゲーム中 |
| `paused` | ポーズ中（Pキー） |
| `gameover` | ゲーム終了 |

### ゲームフロー

```
[待機] → (Enter/Space) → [プレイ]
[プレイ] → (P) → [ポーズ]
[プレイ] → (ゲームオーバー) → [ゲームオーバー]
[ゲームオーバー] → (Enter) → [待機]
```
