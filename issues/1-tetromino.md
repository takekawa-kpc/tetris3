# Issue 1: テトロミノ定義（7種、7-bag randomizer）

## 概要

7種類のテトロミノ（I, O, T, S, Z, J, L）を定義し、7-bag randomizer でランダムに取得する。

## 仕様

### テトロミノ定義

| 名前 | 形状 | 色 |
|------|------|-----|
| I | 一直線 | シアン `#06b6d4` |
| O | 2x2四角 | 黄色 `#eab308` |
| T | T字 | 紫 `#a855f7` |
| S | ずらしS | 緑 `#22c55e` |
| Z | ずらしZ | 赤 `#ef4444` |
| J | J字 | 青 `#3b82f6` |
| L | L字 | 橙色 `#f97316` |

### 7-bag randomizer

- 7種を1組としてランダムにシャッフル
- 1組が尽きたら新しい7種をシャッフルして補充
- 同じピースが連続して2回以上出現しない
